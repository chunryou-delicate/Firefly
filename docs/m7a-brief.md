# M7a 사전 등록 — 탈출 회로 확인: 다가오는 자극이 점프 명령까지 가는가

총괄 세션 작성 (2026-10-23). **실행 전에 쓴 문서다.** 결과를 보고 고치지 않는다.

> **보고 대상:** 총괄 세션. 이 지시를 전달한 메시지의 `from-name`을 쓴다.

먼저 읽을 것: `docs/m7-game-ladder.md`(배경·데이터 표·규칙), `docs/m3-report.md`(이득 선택 규칙), `docs/m2f-report.md`·`docs/m2h-report.md`(동작점과 세 숫자 점화 규칙), `flysim/engine/lif.py`, `flysim/graph/annotations.py`.

의존성: 기존 그대로.

## 질문
한쪽 `LC4`·`LPLC2` 전체에 "다가오는 물체" 전류를 넣으면, **같은 쪽** 거대 신경섬유(`DNp01`)가 켜지고 반대쪽은 조용한가. 거기서 점프 운동뉴런(`TTMn`)까지 가는가.

## 뉴런 집합 (전부 데이터 조회로 만든다. 0건이면 예외)
- 입력: `type ∈ {LC4, LPLC2}`, 좌우는 `somaSide` → 없으면 `rootSide` → 없으면 instance 접미사. 총괄 확인값 LC4 71/55, LPLC2 94/91.
- 판독 1: `type == DNp01`, 좌우 각 1개.
- 판독 2: `type == TTMn`. 개수와 좌우를 먼저 조회해 리포트에 적는다.
- 배경 감시: 그 밖의 전부.

## 자극 (가정 표기)
다가오는 원판이 300 ms 동안 커지는 상황을 흉내 낸다. 감지기 출력은 각팽창 속도에 비례한다고 가정하고, 전류를 0에서 최대까지 300 ms 동안 지수적으로 키운 뒤 끊는다. 앞 200 ms 무자극, 뒤 300 ms 관찰. 한쪽 집합의 모든 세포에 같은 값(세포별 이질성 없음, 가정).

조건 넷: **왼쪽만 · 오른쪽만 · 양쪽 · 없음(대조)**.

## 동작점 둘 (새로 찾지 않는다)
- **P1 조용한 전도도 모델**: `synapse="conductance"`, `g = 3.162e-4`(DEFAULT_G_CONDUCTANCE), 노이즈 0, 적응 0.
- **P2 적응 배경**: `adapt_g_b = 8.0`, `g = 5.36539e-4`, `noise_sigma = 29.13`(M2f 강건 동작점).
dt 1 ms. 노이즈가 없는 P1은 시드 1개로 충분하고, P2는 노이즈 시드 0~9.

## 이득 선택 (M3 규칙을 그대로 쓴다)
최대 전류 `a_in`을 로그 격자로 올리며, 아래 PASS를 **점화 없이** 처음 통과하는 최소값을 동작점마다 고른다. 격자 상한 5120. 통과가 없으면 그것이 결과다.

## 판정 (실행 전에 코드에 박는다)
- **PASS**: 왼쪽만·오른쪽만 조건 각각에서
  - 같은 쪽 `DNp01`이 자극 구간에 스파이크 ≥ 1 (P2는 10시드 중 ≥ 9)
  - 대조 조건에서 그 `DNp01`은 같은 구간 스파이크 0 (P2는 대조 대비 초과가 3 × 표준오차 이상)
  - 반대쪽 `DNp01` 스파이크 수 < 같은 쪽
- **점화**: 세 숫자 규칙. 점화된 점은 PASS가 아니다.
- **기술 지표(판정에 안 씀)**: 같은 쪽 `DNp01` 첫 스파이크 지연(자극 시작 기준, ms), `TTMn` 좌우별 스파이크 수와 지연, 양쪽 조건에서 두 거대 신경섬유가 같이 켜지는지.

## 미리 정해두는 해석
- PASS이고 `TTMn`도 켜지면: 게임 판독은 `TTMn`으로 한다.
- PASS인데 `TTMn`이 조용하면: 게임 판독은 `DNp01`로 하고, 전기 시냅스가 커넥톰에 없는 탓일 수 있다는 가정을 적는다. 연결을 임의로 키우지 않는다.
- PASS가 없으면: M7c 이후는 쓰지 않는다. 결과를 그대로 보고한다.

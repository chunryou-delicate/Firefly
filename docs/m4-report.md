## 6. Interpretation (one paragraph; causes are marked as assumptions)

Under this model the click train drives JO_AB and its direct postsynaptic set; the tables above show how far activity gets at each IPI and whether the first hop depends on IPI. Where a set reads 0 at every IPI, that is the result of this stage and is reported as such. Assumed (not tested here) reason for activity stopping at the first hop: at g = 0.336 with no background activity the summed excitation from JO_post spikes does not reach threshold in the next stage, and no fluctuation-driven low-rate state exists in this current-based model (data-provenance/parameter-decisions.md). Any model change belongs to phase B and is the user's decision.

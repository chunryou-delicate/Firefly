## 무엇을
M7c가 남긴 **실제 재생 묶음 세 개**(`runs/m7c/{jump,dodge,dodge_v2}-brain-seed10/`)를 읽어, 왼쪽에 게임 화면, 오른쪽에 3D 초파리 뇌를 같은 시간축으로 재생한다. 탈출 회로 — LC4·LPLC2(눈 뒤) → 거대 신경섬유(뇌에서 신경삭까지) → `TTMn`(가슴 신경절) — 의 실제 가지가 켜지는 게 보여야 한다.

## 결정된 것 (바꾸지 않는다)
- **재생형**: 서버 없이 열린다. 실시간형은 다음 단계.
- **집합 소속은 묶음의 `run.json`(`neurons.region`/`regions`, `escape` 프로필)에서** 가져온다. 점구름은 위치 전용.
- **시간 정렬은 `t_ms` 하나.** 화면은 현재 시각 이하의 마지막 게임 프레임을 띄운다.
- 탈출 회로 골격 묶음(`data/cache/skel-{LC4,LPLC2,DNp01,TTMn}`)을 겹쳐 그린다.

## 정할 것 (네 판단, 리포트에 근거)
- **파일 형태**: `flysim-3d.html`에 "게임 재생" 모드를 넣을지, 별도 `flysim-game.html`을 만들지. 렌더러를 두 벌 만들지 않는다는 원칙(M6d)을 지켜라.
- **프레임 읽기**: 묶음의 `frames.npz`를 브라우저에서 직접 풀지, 생산 쪽에 원시 이진(`frames.bin` + 색인 json)을 추가해 달라고 할지. 후자면 **직접 만들지 말고 총괄에 요청**하라(생산 코드는 서버 창 소관).

## 화면에 반드시 넣을 것 (사다리 규칙 4·정직성)
- "감지기는 직접 짠 것이고, 감지기부터 거대 신경섬유까지만 배선도다" 표시.
- **점프·이동 사건 표시**: `game.json`의 사건(점프, 이동, 충돌, 통과)을 게임 화면과 타임라인에 찍는다. 거대 신경섬유 스파이크와 나란히 보여서, 행동이 입력을 따랐는지 잡음을 따랐는지 눈으로 보이게 한다.
- **자발 발화가 보여야 한다.** M7c에서 거대 신경섬유는 입력 없이도 초당 약 2발 쏜다. 그게 이번 결과의 핵심이라 숨기지 말고 보여준다.
- 점수, 에이전트 종류, 시드, `k`, 동작점을 머리에.
- 판 전체 발화 비율이 뷰어 경고선에 가깝다(뛰어넘기 묶음 85.4 %). 이건 배경이 오래 쌓인 값이라는 설명을 경고와 함께 띄운다.
